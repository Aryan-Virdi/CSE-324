# Carrot Field Vision System

</div>


## Motivation

Bolthouse Fresh Foods stands out as a leader in carrot production, functioning as a grower, packer, processor, and shipper. We would like to be able to better optimize our growing practices. In order to do this, we must first analyze the steps which we currently use to grow carrots. We would like to analyze the seeds in our fields to better understand how they are planted and grown.

## Problem Statement

Develop a vision system that can observe and analyze carrot seeds starting at day 80, until the end of the growth cycle. 

### Goals

- [ ] Create a vision model system which can estimate and store carrot density information from images in order to estimate yield

## Requirements: 
* A computer vision model capable of counting the number of carrots in an image
* Meaningful data analysis on annotated data 


## Bonus Features
* Heatmap Visualization 
* User authentication
* Carrot disease detection
* Carrot weed detection

### Software Stack / Technologies Used

- Language: Python
- Framework: Streamlit, Docker
- Database: PostgreSQL, SQLModel
- Models: You Only Look Once (YOLO), Segment Anything Model (SAM), RESNET
